## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `entry.png` (1024×1024, one day's news) into `out/`. The program uses only the Python standard library and produces byte-identical output on every run.

`render_image.py` drew `entry.png` at build time (Pillow, local only — the grader never runs it).
